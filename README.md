# Kalorifer Peteğinin Milli Savunma Doktrini

> **Resmi Uyarı:** Bu yazılım bir ısıtma cihazı değildir. Bu yazılım bir savunma bakanlığıdır. Peteğin rütbesi generaldir. Vana dönüş yönü milli meseledir.

## Bu nedir?

Kış geldiğinde üst kat “ben kısıyorum” der. Alt kat “ben açıyorum” der. Peteğ ortada kalır. Bu yazılım o ortada kalışın **resmi doktrinini** üretir.

Çalışır. Gerçekten. Isıtmaz. Ama rapor yazar. Rapor ısıtmaz ama vicdanı yakar.

## Kurulum

```bash
python3 doktrin.py
```

Bağımlılık yoktur. Çünkü bir milletin doktrini pip ile kurulmaz.

## Kullanım

Program şunları sorar:
- Üst kat vanayı kıstı mı?
- Alt kat battaniye mi yoksa manifesto mu örtündü?
- Peteğin moral durumu nedir?

Sonra çıktı olarak:
- Tehdit seviyesi
- Karşı önlem
- Resmi bildirge
- Peteğe verilen rütbe

üretir.

## Tehdit Seviyeleri

| Seviye | Anlamı | Peteğin Tepkisi |
|--------|--------|-----------------|
| 0 | Yaz | Peteğ tatilde |
| 1 | Iılık | Peteğ uyanıyor |
| 2 | Serin | Vana diplomatik nota |
| 3 | Üşüme | Genelkurmay toplanır |
| 4 | Donma | Milli seferberlik |
